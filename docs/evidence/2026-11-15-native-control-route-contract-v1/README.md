# Exact native control intent contract

The Core Project control route previously accepted a raw request that could not be processed: the request model omitted the native control sequence, and a Project-level Task scope serialized as null rather than the empty scope required by the native intent contract. It returned a durable pending receipt before discovering the mismatch.

The route now requires a strict positive integer `control_sequence` and reads the existing server-owned human ERP intent before changing the Core inbox. Project, Task, command ID, sequence, action and actor must match exactly. A missing sequence is rejected by request validation; a missing, changed or superseded intent returns HTTP 409 without inbox or audit mutation. Project-level Task scope is consistently the empty string. Create the human control in ERP, then mirror its exact intent; this endpoint neither creates native controls nor substitutes an actor. The existing event processor rechecks the native intent after persistence, retaining its normal atomic application and ACK reconciliation.

Compatibility: legacy raw callers must use the exact native intent fields. Their previously accepted requests could not complete, so silently inventing a sequence or actor would grant authority that never existed. Pause/Stop remain available after Project eligibility revocation when the exact native human intent and revision match. Authentication and Task ownership checks are unchanged. Native readback failures return HTTP 503 with existing sanitized ERP validation details; existing HTTP errors are preserved.

Eight focused tests execute the actual Pydantic model and route against a real temporary governance ledger. They cover validation before entry, mismatched/malformed readback with zero inbox writes, exact Project control plus duplicate idempotence and normal native ACK, native supersession between persistence and processing, Task ownership/authentication, Pause after eligibility revocation, safe actual ERP readback failures, and an already acknowledged native sequence whose mirrored Core command reconciles through receipt GET without another ACK POST. ERP responses and dispatch scheduling are controlled; no network, live database or model actions occur. The selected runtime export overlays only the model, route and its description on the existing live router, preserving other live code.
